Continuous Documentation Automation

A deterministic, verifiable 4-stage pipeline that bridges the documentation-debt divide.

STAGE 01

AST & Change Detection

Parses syntax trees to extract classes, functions, type hints, and parameter signatures while tracking revisions.

STAGE 02

Source-Grounded Docs

Generates technical references citing exact source files and line ranges, avoiding ungrounded speculative claims.

STAGE 03

Isolated Code Verification

Extracts runnable snippets into sandboxed subprocesses with strict timeouts. Fails trigger bounded correction loops.

STAGE 04

Reviewable PR Staging

Prepares unified diffs and stages GitHub pull requests with structured checklists for human review.

Core Capabilities

Built for engineering teams that value precision, reproducibility, and safety.

Change-Aware Synchronization

Documentation updates are triggered directly by AST structural diffs rather than relying entirely on manual discipline.

Executable Code Verification

All supported code examples run in an isolated environment. Broken examples never silently slip into published docs.

Bounded Self-Correction

When snippet execution fails, the traceback feeds into a bounded repair loop that re-verifies candidates before staging.

Source-Grounded Explanations

Claims reference explicit source files, line ranges, and AST nodes. Never hallucinates files outside repository scope.

Reviewable Git Proposals

Prepares transparent unified diffs and commits to dedicated documentation branches ready for peer review.

Flexible Hybrid AI Engine

Operates either with LLM providers (Gemini/OpenAI) or completely offline with deterministic AST generation.

Trust & Operational Boundaries

We do not promise zero drift or guaranteed perfection. We provide verifiable checks and transparent audit trails.

No Arbitrary Code Execution on Host

Snippets run in bounded subprocesses with timeouts, restricted directory paths, and isolated process groups.

Human-in-the-Loop Review

Every automated sync creates a staged proposal or pull request. No documentation is silently pushed to production unreviewed.

Fact vs. Suggestion Distinction

The AI Assistant distinguishes verified AST facts from AI recommendations and clearly admits unindexed repository files.

Persistent Audit Records

Every verification run, execution duration, stdout capture, and correction attempt is stored persistently in SQLite.
